Aide — Comprendre la démarche RACI

Objectif : aider le chef de projet à savoir par où commencer et quels boutons utiliser selon qu’il dispose déjà d’une Feuille de route ou non, et selon que le projet est simple ou structuré (instances COPIL / comité…).

1. Par où commencer ?

  • Vous avez déjà un RACI JSON → bouton « Importer JSON RACI ».
  • Vous avez une Feuille de route → elle est déjà dans le Pivot (phases + chantiers). Utilisez « Pré-remplir depuis la feuille de route (Pivot) » si vous souhaitez initialiser la matrice.
  • Vous démarrez de zéro → dans la fenêtre de démarrage, choisir « Créer un nouveau RACI vierge » : l’outil vous demande le titre du projet puis vous ajoutez acteurs et activités.

2. Scénarios typiques

  • Petit projet simple, sans instances formelles
    → Créer un RACI vierge → ajouter 3–5 acteurs (MOA, MOE, DSI…) → ne pas activer la colonne Instances → remplir quelques activités.
  • Projet structuré avec COPIL & comités
    → Créer un RACI vierge ou importer un RACI existant → cliquer sur « Activer la colonne Instances… » → cocher COPIL / Comité de projet / Suivi hebdo pour chaque acteur → utiliser la vue par instance pour préparer l’organigramme de projet.
  • Gros projet avec Feuille de route déjà saisie
    → Importer la Feuille de route → Pré-remplir depuis la feuille de route (Pivot) pour créer une activité par chantier → affiner les intitulés d’activités → affecter R / A / C / I.

3. RACI vierge ou Feuille de route ?

  • Feuille de route pas encore faite → vous pouvez quand même créer un RACI vierge, mais la colonne « Chantier » restera vide (ou non utilisée).
  • Feuille de route disponible → l’import vous donne :
    • le titre du projet ;
    • la liste des phases ;
    • les chantiers par phase, que vous pouvez lier à chaque activité.

4. Instances ou pas ?

  • Si vous ne cochez aucune instance, ce n’est pas bloquant : le RACI continue de fonctionner (utile pour les projets hors marché ou très simples).
  • Si vous utilisez COPIL / comités, activez la colonne Instances pour :
    • voir quels acteurs siègent dans quelle instance ;
    • utiliser la vue par instance pour préparer vos supports de gouvernance.

5. Règles R / A / C / I (rappel rapide)

  • R – Réalise : exécute concrètement l’activité.
  • A – Approuve : porte la responsabilité finale (un seul A par activité).
  • C – Consulté : donne un avis avant décision (échanges nécessaires).
  • I – Informé : reçoit l’information, sans être consulté.

Le bouton « Vérifier le RACI » contrôle automatiquement la présence d’au moins un R, l’unicité de A, et la cohérence avec la liste d’acteurs.
